# Prose Gap Polish

Adapted from zenstory-ai's prose-gap-polish five-step method (MIT),
retargeted from technical docs to fiction: turn a draft only its author can
read into one a first-time reader follows, in five ordered passes.

## Pass 1 — merge telegraphic fragments, kill coined jargon

- Fuse two-to-four stub sentences from one causal chain into sentences with
  breath; do not pile up clauses to do it.
- Give every action its actor. Subjectless chains read as stage directions.
- Coinages and internal shorthand come out: write the concrete act and the
  concrete object ("the calibration" → "the checksum pass on the drive").

## Pass 2 — strip defensive and meta scaffolding

- Defensive hedges ("needless to say", "of course", "as everyone knows") —
  cut.
- Narrator asides explaining what a beat means — cut; the scene carries it.
- Over-explained motivation — cut back to the choice itself.

## Pass 3 — resolve ambiguity

- Pronouns with two possible antecedents: name the one meant.
- Modifier boundaries: "Elias told Kaelen the file was corrupt" — who
  believes it? Attach the clause.
- Same word, two meanings across a scene: split the senses.

## Pass 4 — fill information gaps (zero-background reader)

Read as someone who has never met this world. Where the text assumes a
fact the story has not yet placed, place it — one clause, from what the POV
character would actually perceive. Then re-check the fact against
`continuity/` so the patch does not invent canon.

## Pass 5 — repair logic breaks

- Time flows forward: check event order against `plot/timeline.md`.
- Cause precedes effect; a character cannot react before the reveal.
- Numbers and counts in prose match the records (`story continuity .`).
- Setups resolve or are tracked as open loops in `continuity/questions/`.

## Order matters

Do not run pass 5 before pass 1: merging fragments changes the apparent
logic. Finish each pass across the whole scope before starting the next.
