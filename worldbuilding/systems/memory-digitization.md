# Memory Digitization Protocol

## Overview

Personal memories are scanned via a neural interface into digitized archive nodes, indexed, and stored for later retrieval or rewrite.

## Rules & Limitations

The records are cryptographically sealed; alteration requires a root key and destabilizes the subject's mind if performed clumsily.

## History

Adopted under the Oversight Committee to standardize and "curate" New Providence's past.

## Practitioners

Archivists perform routine capture; Director Vane controls the root infrastructure.

## Impact on Society

Whoever controls memory controls truth.
