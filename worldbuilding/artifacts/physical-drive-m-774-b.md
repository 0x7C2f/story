# Physical Drive M-774-B

## Description

A small, dark rectangular physical drive, noticeably older hardware ("untaceable hardware, old school").

## Function

Stores raw sensory memory data off the main corporate network. Allows for the viewing and manipulation of memory data outside the standard Nexus Archives protocols.

## History

Elias pulled this drive from his routine work at the Nexus Archives when he discovered a glaring anomaly in the memory designated M-774-B.

## Current State

Currently in Elias's possession, though it was recently connected to Kaelen's rig in the Undercity for decoding.
