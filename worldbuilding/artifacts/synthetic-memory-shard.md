# Synthetic Memory Shard

## Description

A small, crystalline shard that pulses with a faint, inner light. The geometry inside it is fractal and alien.

## Function

Stores a specific memory. In this case, an alien, synthetic code rather than typical human sensory or emotional data.

## History

It was brought to Elias Thorne in a dark alley by a paranoid, disguised client who desperately wanted it scrubbed from their own wetware.

## Current State

Currently in the possession of Elias Thorne, who extracted it and discovered its true, terrifying nature.
