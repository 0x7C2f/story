# Project: Synchronization

## Definition

The Oversight Committee's end-stage memory operation: a broadcast infrastructure
built to push a single city-wide memory update to every citizen of New Providence
at once. Where the [Batch Protocol](batch-protocol.md) rewrites memories
industrially but record by record, Project: Synchronization overwrites the
collective memory of the entire city simultaneously — a mass overwrite from which
no one would be left who remembered asking a question.

Elias first sees it in chapter 8, at the core of Director Vane's personal
architecture, where it sits "proudly displayed" rather than hidden:

> *Project: Synchronization. Status: Pending City-Wide Implementation.*

The architecture was finished before it was ever launched. It is fed by Director
Vane's mod lab through the [Central Broadcast Tower](central-broadcast-tower.md),
and the counter-broadcast in chapter 11 severs that feed and kills it.

## Usage Notes

Use "Project: Synchronization" for the program itself and "the synchronization"
or "the sync feed" for the live signal. "The mass overwrite" is the characters'
phrase for what it would have done — use it when the stakes are being described
rather than the machinery.

**The root key defeats this project from outside it.** The
cryptographic root key is the separate credential that authorizes access to the
broadcast network; it is the one thing with clearance high enough to interface
with the synchronization infrastructure, which is why stealing it from Vane's
vault (chapter 8) and turning it into a counter-broadcast (chapter 11) is the
only route the story has. Do not conflate the two: the root key is evidence
turned weapon, Project: Synchronization is the threat it is aimed at.

**Status as of chapter 17:** failed, not dismantled. The overwrite never ran, and
the Committee's command structure fractured when its own internal records
unspooled on air — but the infrastructure survived, and chapter 17 has Elias
proposing to build a shadow network on the still-active root key precisely
because the Committee will regroup.
