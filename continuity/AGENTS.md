# Folder Guide: continuity

This folder tracks the state of the story. It is the memory of the record.

## Contents

- `state.md` is the continuity ledger. Record every story fact that must stay true.
- `exemptions.md` is the log of dismissed findings. Read its rules before you edit it.
- `questions/` tracks open questions. Read `questions/AGENTS.md`.
- `promises/` tracks setups that must pay off. Read `promises/AGENTS.md`.
- `clues/` tracks the mystery clues. Read `clues/AGENTS.md`.
- `guides/` holds the text of the folder guides. One file is one guide.

## Rules

1. Update `state.md` in the same run as the change it records.
2. Add one exemption only for a finding with a clear narrative or structural reason.
3. Run `story continuity .` after you revise chapters.
4. Keep `guides/` in step with the folders it describes.

## Do Not

- Do not add an exemption to bypass a valid check failure. Fix the finding first.
- Do not edit `_index.md` files in the subfolders by hand.
- Do not add story prose to this folder. Story prose belongs in `chapters/`.
