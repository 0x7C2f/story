# Folder Guide: agent

This folder holds autonomous run state only.

## The work is never done

There is no `PAUSED` switch and no stop file. A run never exits because there is "nothing new" to write. When the agent has no new content to add, it improves, merges, or enhances existing content: tighten prose, fix continuity, fold duplicate scenes together, update indexes and wordcounts, refresh character and worldbuilding files. Every run must leave the record tighter than it found it.

## Rules

1. At the start of every run, confirm `agent/` contains only `AGENTS.md`; remove any scratch files before finishing.
2. Prefer improving or merging existing story content over writing net-new content when no gap exists.
3. Never stop a run for lack of new material — enhance old content instead.
4. Delete every file besides `AGENTS.md` from this folder before finishing a run.

## Do Not

- Do not store scratch files or notes in this folder.
- Do not create a `PAUSED` stop file or any equivalent run-halt switch.
